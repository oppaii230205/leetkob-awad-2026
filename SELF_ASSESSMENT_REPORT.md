## What we completed and why

We chose publishing because it is the consequential boundary between a proposed result and marks students can see. A wrong retry behavior can create duplicate events; a class-ownership error can expose or publish another TA's data; a missing pending-review guard can bypass the human decision required by the brief.

We use a small TypeScript/SQLite application to make those rules observable. Native HTTP keeps contract tests at the client boundary. SQLite's immediate transaction coordinates writers and commits the receipt, immutable mark snapshots and audit event together. A deliberately failed audit insert verifies rollback after earlier writes. A separate connection verifies persisted replay; a held write lock verifies a safe retryable 503. These checks add evidence beyond one successful POST.

The initial implementation and harness were not automatically treated as correct. We recorded a real test-helper mistake, corrected its scalar-value assertion separately, resolved development-tool advisories without ignoring npm peers, then injected two explicit contract violations. In both cases the required gate refused the owner-account merge. Green came from restoring implementation behavior, not editing the oracle.

## What we did not manage / limits

No required PA2 technical item is intentionally omitted. Full identity/accounts, upstream counted-submission selection, grading calculations, C++ sandbox/attack suite, model review, dev-set eval thresholds, TA UI, appeals, deployment, telemetry and the 80-submission load test are later milestone work. PA2's demo authentication and synthetic upstream records are documented boundaries, not a production deployment claim. The concurrency test is not presented as that future load test.

No model account or key is used here, so no paid provider-side limit is claimed: the current integration is absent and its budget/cost is zero. The future model choice/cap must be reviewed before activation. This is appropriate to the rubric's stated pre-LLM checkpoint.

The local correction to a defective test helper is disclosed rather than hidden. The meaningful failing gate experiments change source only, and the final tag retains the repaired source and unchanged contract tests.
